# 婚禮祝福牆當天操作清單

Oct 8, 2026 · @Corner

Nov 19, 2026 婚禮當天，祝福牆需要兩個人：一位用手機審核祝福，一位顧大螢幕電腦；開場前 30 分鐘完成檢查就能放心交給賓客。

## 婚禮前一週

這些做完，當天只要開機就能用。

- [ ] 網站已放上網路，用手機打開正式網址能看到紅布幕首頁
- [ ] 新娘、新郎、伴娘各用自己的手機（iPhone 和 Android 都要有）實際錄一段影片、拍一張照片，送出後在審核頁看得到
- [ ] 從 LINE 傳網址給自己再點開，確認會跳到 Safari／Chrome，相機打得開
- [ ] 審核帳號的 Email 和密碼，伴娘手機裡已經登入過一次
- [ ] 大螢幕要用的筆電：已登入審核頁，按「開啟祝福大螢幕」能正常播放
- [ ] 跟場地確認投影機接頭（HDMI／USB-C）和音響怎麼接，影片要有聲音
- [ ] 確認場地 Wi-Fi 名稱和密碼；另外準備一支手機熱點當備案
- [ ] 網站上線後才列印 QR code 桌卡（印得太早，QR code 會連到錯的網址）
- [ ] 測試時留下的祝福，在審核頁按「隱藏」清掉

## 當天分工

至少要有審核和大螢幕兩個人，不要讓新人自己顧。

| 角色 | 誰 | 要做的事 | 用什麼 |
| --- | --- | --- | --- |
| 審核 | 待定（建議伴娘） | 手機一震動就看新祝福，按「通過」或「隱藏」；不合適的立刻隱藏 | 自己的手機、審核頁 |
| 大螢幕 | 待定（建議婚企或投影負責人） | 開場前開好大螢幕、接投影和音響；中途卡住就重新整理 | 筆電、投影機、音響線 |
| 現場協助 | 待定（可由接待兼任） | 招呼賓客掃桌卡 QR code；有人相機打不開時幫忙「用 Safari 開啟」 | 桌卡、自己的手機 |

待確認：三個角色各由誰負責。

## 當天流程

1. **開場前 60 分鐘**：大螢幕筆電接上投影和音響，連上 Wi-Fi，用審核帳號登入審核頁。
2. **開場前 30 分鐘**：在審核頁按「開啟祝福大螢幕」，點一下「點一下開幕」。確認畫面全螢幕、影片有聲音。
3. **開場前 20 分鐘**：審核的人用手機打開審核頁，先點一下畫面（這樣有新祝福時才會叮一聲）。手機保持亮著，不要關掉這個分頁。
4. **開場前 10 分鐘**：有人用桌卡掃一次、拍一張照片送出，審核頁會叮一聲，按通過後大螢幕會在下一則插播。測完把這則隱藏。
5. **婚禮進行中**：審核的人每次手機震動就看一下；大螢幕的人不用動它，卡住時參考下一段。
6. **散場後**：大螢幕可以直接關掉。祝福都存在雲端，婚後再下載。

## 出狀況怎麼辦

大部分狀況重新整理就好；祝福都存在雲端，不會不見。

| 狀況 | 怎麼處理 |
| --- | --- |
| 賓客說相機打不開 | 多半是從 IG、Facebook、LINE 裡點開的。請他點右上角「⋯」→「在 Safari／瀏覽器中開啟」；再不行就按「允許使用相機」或改用「從相簿選」 |
| 賓客說影片太大傳不上去 | 從相簿選的影片上限 20MB。請他改按「錄一段祝福影片」在網頁裡直接錄 |
| 大螢幕卡住、白屏 | 按鍵盤 ⌘R（Windows 是 F5）重新整理，再點一次「開幕」 |
| 大螢幕出現「Backstage only」 | 這台電腦沒登入。按畫面上的「前往審核頁登入」，登入後再按「開啟祝福大螢幕」 |
| 影片沒有聲音 | 確認音響線有接、電腦音量沒靜音；重新整理後一定要「點一下開幕」，否則瀏覽器不會放聲音 |
| 場地 Wi-Fi 斷了 | 大螢幕會繼續輪播已經下載好的祝福。改連手機熱點，新的祝福就會進來 |
| 審核手機沒有叮一聲 | 手機不要靜音、畫面不要鎖住；iPhone 不支援震動提醒，要看分頁標題的「(3) 祝福審核」數字 |
| 有不合適的內容已經上大螢幕 | 審核頁「已通過」分頁按「撤下」，大螢幕會立刻跳到下一則 |

## 婚後

1. 用電腦登入審核頁，按右上角「全部下載」。會得到一個壓縮檔，裡面是所有影片、照片，和一份「祝福留言清單」（Excel 可以打開）。檔案大，請用電腦、不要用手機下載。
2. 壓縮檔存兩份：電腦一份、Google 雲端硬碟一份。
3. 確認備份打得開之後，再決定要不要關掉網站、清空 Supabase 的空間。
